# EGX Flow · سيولة قطاعات البورصة المصرية

أداة بتوريك **الفلوس رايحة على أنهي قطاع وجاية منين** في البورصة المصرية، بنفس فكرة شاشة "سيولة القطاعات" في التطبيقات الخليجية، ومعاها مزايا إضافية.

## المزايا

| القسم | بيوريك إيه |
|---|---|
| الفلوس رايحة على أنهي قطاع | خريطة مربعات: حجم المربع = نصيب القطاع من تداول السوق، واللون = سيولته مقارنة بالمعتاد |
| السيولة مقابل حركة الأسعار | الخانات الأربع: تجميع، تصريف، صعود بسيولة ضعيفة، عزوف |
| الفلوس جاية منين ورايحة فين | رسم تدفق من القطاعات اللي خسرت نصيب من التداول للقطاعات اللي كسبت، بمبالغ تقديرية بالجنيه |
| صافي التدفق | ضغط شراء أم بيع داخل كل قطاع (فكرة Chaikin Money Flow) |
| خريطة الدوران | السيولة مقابل الأداء (اليوم / أسبوع / شهر) |
| اتساع الحركة | عدد الصاعد والهابط في كل قطاع، علشان تعرف لو سهم واحد بس هو اللي شايل القطاع |
| أسهم عليها سيولة غير عادية | الأسهم اللي حجمها ضعف متوسط 10 أيام أو أكتر |
| تاريخ دوران السيولة | خريطة حرارية يوم بيوم + عدد أيام الدخول المتتالية |
| تفاصيل القطاع | اضغط على أي قطاع تشوف أسهمه وأكتر سهم مسيطر على سيولته |
| تنبيه تليجرام | ملخص آخر اليوم على تليجرام (اختياري) |

وفيه كمان اختيار فترة المقارنة (10 / 30 / 60 يوم) وتحديث تلقائي كل 5 دقايق.

## مصدر البيانات

الأداة بتستخدم **TradingView Scanner** (`scanner.tradingview.com/egypt/scan`). مجاني ومش محتاج مفتاح، وطلب واحد بيجيب كل أسهم EGX ومعاها السعر والتغير وقيمة التداول ومتوسطات الأحجام والقيمة السوقية والأداء الأسبوعي والشهري.
- البيانات غالبًا **متأخرة حوالي 15 دقيقة** أثناء الجلسة.
- ده API **غير رسمي**، يعني ممكن يتغير في أي وقت. لو اتغير، كل التعديل هيبقى في دالة `fetch_stocks()`.

بدائل لو احتجت مصدر رسمي أو مدفوع:
- **EODHD**: عندهم البورصة المصرية بكود `EGX` (نهاية يوم + لحظي + تاريخي) باشتراك شهري. مناسب لو عايز تملأ تاريخ قديم.
- **oanor EGX API**: فيه خطة مجانية (100 طلب في الشهر) وخطط مدفوعة، وبياناته أصلًا جاية من TradingView.
- **ICE / LSEG / مباشر برو**: بيانات مؤسسية Level 1 و Level 2 بأسعار عالية.
- **موقع البورصة egx.com.eg**: التقارير اليومية فيها صافي تعاملات المصريين والعرب والأجانب، والمؤسسات مقابل الأفراد. مفيش API، فلازم سحب يدوي أو scraping. ممكن تتضاف كمرحلة جاية.

## التشغيل

### 1) على جهازك (أسرع طريقة)
محتاج Python 3.9 أو أحدث، ومفيش أي مكتبات إضافية.
```bash
python serve.py
```
هيسحب البيانات كل 5 دقايق أثناء الجلسة، ويفتح الداشبورد على `http://localhost:8000`.

ولو عايز سحب مرة واحدة بس:
```bash
python collector.py
python -m http.server 8000
```

### 2) مجانًا على GitHub وتفتحه من الموبايل
1. اعمل repo جديد على GitHub وارفع فيه ملفات المشروع.
2. **Settings → Pages → Deploy from branch → main / root**.
3. **Settings → Actions → General → Workflow permissions → Read and write**.
4. من تبويب **Actions** شغّل `Collect EGX data` يدوي أول مرة.
5. بعد كده هيشتغل لوحده كل 15 دقيقة من الأحد للخميس أثناء الجلسة، والداشبورد هيبقى على `https://<username>.github.io/<repo>/`.

### 3) تنبيه تليجرام (اختياري)
1. اعمل bot من @BotFather وخد الـ token.
2. ابعت أي رسالة للـ bot، وبعدين افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخد منها الـ `chat.id`.
3. على GitHub ضيفهم في **Settings → Secrets → Actions** بالأسماء `TELEGRAM_BOT_TOKEN` و `TELEGRAM_CHAT_ID`.

هيوصلك ملخص يومي الساعة 12:50 UTC، يعني 2:50 بتوقيت القاهرة في الشتا و3:50 في الصيف.

لو بتشغّل على جهازك:
```bash
set TELEGRAM_BOT_TOKEN=...   # Windows (على ماك/لينكس استخدم export)
set TELEGRAM_CHAT_ID=...
python collector.py --notify
```

## تصنيف القطاعات
`sectors_map.csv` فيه ربط الأسهم الكبيرة والنشطة بقطاعات البورصة المصرية. أي سهم مش موجود فيه بيتصنف تلقائيًا من قطاع TradingView المترجم.
- **راجع الملف وعدّله على حسب التصنيف الرسمي اللي إنت شغال بيه.**
- الـ collector بيطبعلك الأسهم اللي مالهاش تصنيف علشان تضيفها.

## إزاي بنحسب الأرقام
- **نصيب القطاع** = قيمة تداول القطاع ÷ قيمة تداول السوق.
- **السيولة مقابل المعتاد** = قيمة تداول القطاع اليوم ÷ (متوسط الحجم للفترة × السعر) − 1.
- **حركة الأسعار** = متوسط تغيّر أسهم القطاع، مرجّح بالقيمة السوقية.
- **جاية منين ورايحة فين**: الفرق بين نصيب القطاع اليوم ونصيبه المعتاد. السالب معناه فلوس خرجت والموجب فلوس دخلت، والخارج بيتوزع على الداخل بالتناسب. ده تقدير لدوران الاهتمام، مش تتبع أوامر فعلية.
- **صافي التدفق** = Σ CLV × قيمة التداول ÷ قيمة تداول القطاع، و CLV = ((الإغلاق − الأدنى) − (الأعلى − الإغلاق)) ÷ (الأعلى − الأدنى).

## الملفات
```
index.html          الداشبورد (صفحة واحدة، مفيهاش مكتبات خارجية)
collector.py        سحب البيانات وحفظ data/latest.json و data/history.json
serve.py            تشغيل محلي (سحب كل 5 دقايق + سيرفر)
sectors_map.csv     ربط كل سهم بقطاعه
.github/workflows/  تشغيل تلقائي على GitHub
```
للتجربة من غير إنترنت: `python collector.py --demo` بيعمل بيانات تجريبية.

> أداة تحليلية للمعلومات فقط، وليست توصية بالشراء أو البيع.
